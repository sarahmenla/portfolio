Usage Data Pipeline

Usage data that loads itself.

A Node.js and Express service that pulls usage reports from vendor APIs, matches every row to the right record with a multi-tier engine and feeds a dashboard, replacing a spreadsheet rebuilt by hand with one button.

01

Skills it shows

API integration

Pulls COUNTER R5 usage reports from vendor REST APIs on demand, with every endpoint tested in Postman first.

Data matching

Matches on ISBN, title, year and publisher across four tiers, strongest evidence first. Anything ambiguous is flagged for a person, never guessed.

Reliable backend

API keys stay off the client, a second sync is refused while one is running, and vendor errors become plain-English messages.

Professional delivery

Feature branches and reviewed pull requests. It passed acceptance testing and went live.
